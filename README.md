# Movie Review Sentiment Classifier

## Overview

This project builds a binary sentiment classifier that predicts whether a movie review is positive or negative.

## Dataset

The project uses the IMDB movie reviews dataset.

## Tech Stack

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Matplotlib
- Seaborn
- Streamlit
- Hugging Face Datasets
